# Student Performance Analysis & Prediction System

##  Project Overview
This project analyzes student performance factors and predicts students' exam scores using Machine Learning techniques.

##  Objectives
- Analyze factors affecting student exam scores.
- Perform Exploratory Data Analysis (EDA).
- Visualize relationships between student characteristics and exam performance.
- Build Machine Learning regression models.
- Predict exam scores using student information.

##  Dataset
- Source: Kaggle – Student Performance Factors
- Records: 6,607 students
- Features: 19 input features
- Target Variable: Exam_Score

##  Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- IPyWidgets

##  Machine Learning Models
- Decision Tree Regressor
- Random Forest Regressor
- GridSearchCV for Hyperparameter Tuning

##  Final Model Performance

| Metric | Result |
|---|---:|
| MAE | 1.16 |
| MSE | 4.85 |
| RMSE | 2.20 |
| R² Score | 0.657 |

##  Interactive GUI
An interactive GUI was developed using IPyWidgets. Users can enter student details and receive predicted exam scores.
